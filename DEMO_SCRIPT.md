# Demo script (3–4 minutes)

1. Introduce the AI Career & GenAI Research Assistant.
2. In Career Coach mode, request a 12-week AI/ML career roadmap.
3. Upload a public research paper or sample document, index it, and ask a document-specific question.
4. In GenAI Researcher mode, request a structured research brief on RAG or agent evaluation.
5. In Interview Practice mode, request a technical interview question and review the feedback.
6. Show ARCHITECTURE.md and explain ingestion, embeddings, retrieval, tools, and the LLM.
7. Close with the GitHub repository and live demo URLs.
